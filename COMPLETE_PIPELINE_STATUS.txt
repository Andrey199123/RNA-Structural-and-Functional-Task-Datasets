2. Predict protein structure:
```python
import requests

sequence = "MKTAYIAKQRQISFVK..."
response = requests.post(
    'https://api.esmatlas.com/foldSequence/v1/pdb/',
    data=sequence
)
with open("protein.pdb", "w") as f:
    f.write(response.text)
```

3. Extract protein features:
```bash
./RINmaker/RINmaker/build/app/RINmaker \
  -i protein.pdb \
  -o protein_features.graphml \
  rin
```

4. Extract RNA features (once DSSR is installed):
```bash

```
